Build a modern, production-grade React frontend using Vite, Tailwind CSS, Lucide React icons, and React Router for a project called "BlockExam" (Blockchain-Based Secure Online Examination System).

### Visual & Architectural Design
- Clean, modern dashboard UI with dark/light mode accents (slate/indigo/emerald aesthetic).
- Provide a role switcher/mock toggle in the top navbar: "Role: Admin/Faculty" vs "Role: Student", plus a simulated "Blockchain Network Status" indicator (e.g., "Hardhat Localhost: Connected (Chain ID 31337)").
- All mock data should be structured in an isolated `src/mockData.js` file with clean mock API helper functions (`src/services/api.js`) so that connecting to a Node.js + Ethers.js backend later will only require replacing these endpoints.

### Key Pages & Views Required

1. Role Authentication / Quick Switcher:
   - Login / Portal entry screen with toggle between Faculty Login and Student Login.
   - Presets for fast demonstration (e.g., "Log in as Dr. Sharma (Faculty)" and "Log in as Rohan (Student)").

2. Faculty / Admin Dashboard:
   - Overview metrics: Active Exams, Total Students Registered, Verified On-Chain Submissions.
   - Create Exam Form:
     * Exam Name, Exam Code/ID (e.g., BT101), Date, Start Timestamp, End Timestamp, Duration (minutes), Passing Marks.
     * Question Builder: Add multiple-choice questions (question text, 4 options, correct answer).
     * Authorize Students: Input field or CSV paste to whitelist student IDs / wallet addresses.
     * "Deploy Schedule to Blockchain" button: Shows simulated transaction states (Pending, Mined on Block #, TX Hash).
   - Exam Management Table:
     * List created exams with on-chain status badges: `LOCKED`, `ACTIVE`, `ENDED`.
     * Student Attempt Monitor: View who has started, who has submitted, submission hash, and timestamp.
   - Blockchain Audit Explorer View:
     * A table showing tamper-evident logs: Block Number, Transaction Hash (`0x...`), Event Type (`ExamCreated`, `StudentAuthorized`, `ExamSubmitted`), and Timestamp.

3. Student Dashboard:
   - Student Exam List divided into 3 tabs: Upcoming, Live / Active, Completed / Results.
   - Strict Time-Lock Demonstration Feature:
     * For each exam card, show: Start Time, End Time, Duration, and a prominent status badge.
     * Add an interactive "Simulate System Time" dropdown/slider on this page for demo purposes (e.g., test 09:50 AM -> Locked, 10:15 AM -> Active, 11:05 AM -> Closed) to prove that status checks enforce timing rules.
     * Locked Exam State: Disabled "Exam Locked 🔒" button with live countdown timer to start time.
     * Active Exam State: Glowing green badge "Exam Available 🟢" with active "[ Start Exam ]" button.
     * Closed Exam State: Red badge "Exam Closed 🔒" with disabled button.

4. Secure Exam Taking Interface:
   - Fullscreen-style distraction-free exam layout.
   - Top Bar: Exam Title, Question Palette navigation (answered, flagged, unvisited), and a prominent synchronized Countdown Timer.
   - Question Area: Question text, 4 radio select options, "Clear Selection", "Mark for Review", and "Next/Previous" buttons.
   - Submit Confirmation Modal:
     * Summarizes answered vs unanswered questions.
     * Details the on-chain action: "Calculating SHA-256 submission hash and recording immutable proof on-chain."
     * Simulated MetaMask confirmation / loading state showing transaction broadcast.

5. Result & Verification Page:
   - Displays Student Score, Total Questions, Completion Time, and Submission Status.
   - Blockchain Certificate / Tamper-Proof Audit Card:
     * Shows generated Submission SHA-256 Hash.
     * Shows Transaction Hash, Block Timestamp, and a "Verify Integrity" button that recalculates the local hash against the stored on-chain hash and displays a green "Tamper Check Passed: Record Untampered" badge.

### UX & Polish Requirements
- Use Tailwind CSS with clean borders, subtle shadows, and responsive layouts.
- Toast notifications for actions like "Exam Created & Logged on Ledger", "Student Whitelisted", and "Submission Hash Generated".
- Clear visual hierarchy with icons from `lucide-react`.
